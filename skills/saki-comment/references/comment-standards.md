# 多语言代码注释书写规范与好坏对照

本文配合 `saki-comment` 与插件常驻规则使用，综合 **Google Style Guide**、**PEP 257**、**TSDoc / JSDoc**、**GoDoc**、**Rustdoc**、**Javadoc** 与 **Doxygen** 的行业共识，并结合“中文为主、必要处保留英文”的实践约定。

---

## 1. 四条通用黄金原则

1. **行内注释解释「Why」，绝不复述「What」**：代码本身已经说明了“做了什么”，注释只写**业务前提、边界特判、并发/时序约束、算法意图、兼容原因和为什么不选更直觉的写法**。
2. **中英文混排约定**：叙述主体尽量用简洁的简体中文；函数/参数/类型名、错误码、协议名、专有术语（如 `mutex`、`idempotent`、`debounce`）及语言标准标签（`Args:`、`@param`、`TODO`）保留英文。
3. **只给值得注释的地方写注释**：公开 API、核心业务函数、复杂状态机必须写清文档注释；1–3 行自解释极简函数（如简单 getter）不强塞冗长模板；函数内部只注释关键代码块，严禁逐行加注释。
4. **不写作者与日期，不留死代码**：作者和修改时间由 `git blame` 记录；废弃代码由 Git 历史保存，直接删除而非整段注释掉。

## 2. 各主流语言原生文档注释格式

### Python（PEP 257 + Google Style Docstring）
- 使用三双引号 `"""..."""`，首行一句话概括职责，不重复已有类型注解，仅写参数语义/约束、返回值含义与会抛出的异常：
```python
def resolve_retry_delay(attempt: int, base_ms: int = 200) -> int:
    """计算指数退避重试等待时间（毫秒）。

    当上游触发限流时通过截断上限避免长尾请求堆积。

    Args:
        attempt: 当前重试次数，从 1 开始计数。
        base_ms: 基础退避时长（毫秒），必须大于 0。

    Returns:
        本次重试前应等待的毫秒数，最高不超过 30000。

    Raises:
        ValueError: 当 attempt < 1 或 base_ms <= 0 时抛出。
    """
```

### TypeScript / JavaScript（TSDoc / JSDoc）
- 使用 `/** ... */`；TypeScript 中**不要重复写类型**（类型交给 TS 编译器，注释只写语义、约束与副作用）：
```ts
/**
 * 合并用户自定义配置与默认配置，并校验关键字段合法性。
 *
 * @param userConfig - 用户显式传入的局部覆盖项；未提供的字段回退默认值
 * @returns 归一化后的只读运行配置
 * @throws 当超时时间为负数或回调地址格式非法时抛出 Error
 */
```

### Go（GoDoc）
- 在声明正上方使用 `//`（与声明之间不留空行），首句以符号名开头，纯文本流畅表达，不写 HTML 或 Javadoc 标签：
```go
// ParseWindow 解析时间窗口字符串（如 "15m"、"2h"）并返回标准化时长。
// 若输入为空则回退默认窗口，避免调用方在缺省配置下崩溃。
```

### Rust（Rustdoc）
- 外部文档用 `///`，模块级内部文档用 `//!`，支持 Markdown，按需补充 `# Errors`、`# Panics`、`# Safety`：
```rust
/// 从快照文件恢复索引状态。
///
/// # Errors
/// 当文件缺失、校验和不匹配或版本不受支持时返回 `IndexError`。
```

### Java / Kotlin（Javadoc / KDoc）
- 使用 `/** ... */` 与 `@param`、`@return`、`@throws`，在类级别按需说明线程安全性与可变性。

### C / C++（Doxygen）
- 使用 `///` 或 `/** @brief ... @param ... @return ... */`，重点说明指针所有权、空指针约束与线程安全。

## 3. 好注释 vs 不合理注释（主动清理对照表）

| 类别 | 不合理注释（应删除或改写） | 合理做法 |
| --- | --- | --- |
| **复述字面（What）** | `# 如果列表为空则返回 None` | 直接删除（`if not items: return None` 一眼看懂） |
| **过期 / 误导** | `# 默认超时 5 秒`（代码实际已改成 `TIMEOUT = 30`） | 核对真实代码后修正或删除（常量名自解释则直接删） |
| **注释掉的死代码** | 连续 10 行被 `#` 或 `//` 注释掉的旧逻辑 | 直接删除（需要回溯时查 `git log`） |
| **模板凑数 / 作者日期** | `// @author xxx @date 2024-01-01`<br>`@param id - id` | 删除作者日期；`@param id` 要写业务语义，例如“订单唯一主键，用于幂等去重” |
| **关键逻辑缺上下文** | 无注释直接写 `offset = (n + 7) & ~7` 或 `x = -1` | 补一行解释 Why：`# 按 8 字节对齐缓冲区，满足底层 DMA 传输约束` |
